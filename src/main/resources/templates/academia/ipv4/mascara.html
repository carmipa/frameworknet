Leia primeiro; depois veja a divisória andar na régua de 32 bits e teste com os seus endereços.

lightbulbPor que importa

Um endereço IPv4 tem 32 bits divididos em duas partes: a rede (em que "rua" o computador está) e o host (qual "casa" é ele nessa rua). Dois computadores na mesma rede conversam direto; para falar com outra rede, o pacote vai para o roteador. A máscara é o que diz onde fica a divisória entre as duas partes.

calculateComo funciona

A máscara tem bits 1 na parte de rede e 0 na parte de host, sempre nessa ordem. O prefixo é só a contagem dos uns: /24 = 24 uns e 8 zeros = 255.255.255.0.

O endereço de rede é o IP com os bits de host zerados (IP AND máscara). O broadcast é o IP com os bits de host todos em 1. Entre os dois ficam os hosts: 2^(32 − prefixo) − 2 endereços utilizáveis.

Exemplo: 192.168.10.77/27. Sobram 5 bits de host, então o bloco tem 2^5 = 32 endereços. Os blocos andam de 32 em 32 (0, 32, 64, 96…) e o 77 cai no que vai de 64 a 95: rede 192.168.10.64, broadcast 192.168.10.95, hosts de .65 a .94 — 30 hosts.

Atalho: no octeto da máscara que não é 255 nem 0, o tamanho do bloco é 256 − valor. Em 255.255.255.224: 256 − 224 = 32.

Dois casos especiais: /31 é usado em enlace ponto a ponto entre roteadores e aproveita os dois endereços (RFC 3021); /32 é um único host.

reportOnde se costuma errar

  • Contar a rede e o broadcast como hosts (32 em vez de 30 no /27).
  • Responder o próprio IP digitado como endereço de rede.
  • Escrever máscara com uns e zeros misturados, como 255.0.255.0: os uns precisam vir todos juntos, à esquerda.

bookmarkPara lembrar

  • Prefixo = quantidade de bits de rede. Hosts = 2^(bits de host) − 2.
  • Rede: bits de host em 0. Broadcast: bits de host em 1.

visibility Ver

O endereço tem 32 bits. O prefixo diz quantos, da esquerda para a direita, são a parte de rede; o resto é a parte de host. A rede é o endereço com todos os bits de host em 0; o broadcast, com todos em 1.
