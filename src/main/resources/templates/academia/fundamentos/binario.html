lightbulbPor que importa

Dentro do computador tudo vira bit: um sinal que só tem dois estados, desligado (0) ou ligado (1). Oito bits formam um byte. Endereço IP, máscara de rede, porta e o próprio conteúdo de um pacote são números guardados assim — por isso entender binário é a base para tudo o que vem depois na trilha, principalmente máscara e sub-rede.

calculateComo funciona

O binário é posicional, como o decimal: a posição do algarismo diz quanto ele vale. No decimal cada casa vale 10 vezes a anterior; no binário vale o dobro. Num byte, da direita para a esquerda, os pesos são 1, 2, 4, 8, 16, 32, 64 e 128. O valor do byte é a soma dos pesos dos bits acesos.

Exemplo: 1010 0110 tem acesos os pesos 128 + 32 + 4 + 2, que somam 166.

Para o caminho inverso, do decimal para o binário, tire o maior peso que cabe e repita com o resto: 200 = 128 + 64 + 8, então os bits de 128, 64 e 8 ficam acesos: 1100 1000.

Com oito bits existem 256 combinações, de 0 (tudo apagado) a 255 (tudo aceso, que é 2^8 − 1).

reportOnde se costuma errar

  • Ler da esquerda para a direita como se o primeiro bit valesse 1 — o bit da direita é o de peso 1.
  • Esquecer os zeros à esquerda: 101 é 0000 0101, que vale 5, não um byte diferente.
  • Dizer que o máximo de um byte é 256: são 256 valores, mas o maior deles é 255, porque o primeiro é o zero.

bookmarkPara lembrar

  • Pesos de um byte: 128 64 32 16 8 4 2 1.
  • Valor = soma dos pesos acesos. Um bit a mais à esquerda dobra a quantidade de valores possíveis.

visibility Ver

Cada bit tem um peso: o da esquerda vale 128, o seguinte 64, e assim por diante até 1. Para escrever um número, acende-se o maior peso que ainda cabe, e o resto continua para o próximo.
