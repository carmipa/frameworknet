Laboratório · Camadas em ação

layers Camadas em ação

Uma mensagem sai do Host A, ganha um cabeçalho a cada camada, atravessa um switch e chega ao Host B na mesma rede, onde os cabeçalhos são retirados na ordem inversa. Avance no seu ritmo e inspecione cada campo.

{! Cenário declarado — condições iniciais, o que é real e o que está fora do escopo. !}
tune Cenário deste laboratório

Como está montado

  • Host A — IP 192.168.1.10, MAC 02:00:00:00:00:0A
  • Host B — IP 192.168.1.20, MAC 02:00:00:00:00:14 (unicast, localmente administrado)
  • Um switch Ethernet ligando os dois (mesma rede 192.168.1.0/24)
  • Transporte: UDP — um datagrama transporta a mensagem inteira

O que já é conhecido

  • Os dois já estão na mesma sub-rede — não há gateway no caminho.
  • O Host A já sabe o MAC do Host B (o passo de ARP fica fora deste cenário).
  • A porta de destino da aplicação é 7777/udp (demonstração).

Real × didático

  • Real: o tamanho do payload é contado nos bytes UTF-8 da sua mensagem.
  • Didático: os tamanhos de cabeçalho são os mínimos padrão (UDP 8 B, IP 20 B, Ethernet 14 B + 4 B de FCS) e os endereços são de demonstração.
  • Fora de escopo: DNS, roteamento/gateway, NAT, TLS e a negociação do ARP — entram em laboratórios futuros.
