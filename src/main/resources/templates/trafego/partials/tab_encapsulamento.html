Encapsulamento camada a camada. Digite uma mensagem de aplicação e veja-a ser embrulhada pelo modelo TCP/IP (Aplicação → Transporte → Rede → Enlace), cada camada somando seu cabeçalho até virar um quadro Ethernet. No destino, o processo se inverte (desencapsulamento).
lightbulb O que a aplicação quer enviar (o "recheio"). Exemplos: GET / HTTP/1.1 (um pedido de página), Olá, servidor!. Este texto é o que as camadas abaixo vão embrulhar.
lightbulb Transporte: TCP (confiável, ex.: web) ou UDP (rápido, ex.: DNS/vídeo). Portas vão de 1 a 65535 — origem é alta e aleatória (ex.: 51000), destino é a do serviço (80 web, 443 HTTPS, 53 DNS). IPs no formato a.b.c.d (origem = você; destino = o servidor). Na dúvida, use o botão "Exemplo DNS (UDP/53)".
