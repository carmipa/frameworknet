Análise offline. Cole um hex dump de um quadro/pacote e veja os cabeçalhos Ethernet / IP / TCP / UDP / ICMP decompostos e explicados campo a campo. (No Wireshark: botão direito → Copy → as Hex Stream.)
lightbulb Um hex dump é o pacote escrito em hexadecimal (só 0-9 e a-f). O campo já vem com um exemplo pronto (um SYN TCP): é só clicar em Decodificar. Cada linha é uma camada — Ethernet, depois IPv4, depois TCP. Deixe a camada inicial em Auto que o decodificador descobre sozinho. Use Limpar para colar o seu próprio.
